# 大纲编辑规则（参考 Logseq）

Folio 的大纲编辑（日记、卡片里的列表）照搬 Logseq 的交互模型，只借鉴行为，不复制代码（Logseq 是 AGPL）。规则从 Logseq 源码读出（`src/main/frontend/handler/editor.cljs`、`modules/shortcut/config.cljs`、`deps/outliner/src/logseq/outliner/core.cljs`、`components/block.cljs` 的拖放部分），实现集中在 `web/src/editor/outliner/`：所有按键和拖放都调用同一组树操作（移动、缩进、反缩进、合并），不再各自实现。

下文“块”指列表项（`listItem` / `taskItem`）；“可见顺序”指屏幕上从上到下的顺序，跳过折叠起来的子项。

## 编辑时

| 操作 | 规则 |
|---|---|
| `Enter` | 光标前为空、光标后有字：在**上方**插入空块，光标留在原块。其余情况在光标处拆分：后半段成为新块；当前块有展开的子块时，新块成为**第一个子块**，否则成为**下一个同级块**。 |
| `Enter`（空块） | 是父块的最后一个子块：**反缩进**；否则插入新块（同上）。文档模式的卡片里，根层级的空块按 Enter 退出列表（普通文档的习惯）；日记始终按大纲处理。 |
| `Shift+Enter` | 块内换行。 |
| `Backspace`（块首） | 与可见顺序中的**上一块**合并：本块文字接到上一块末尾，光标停在接缝处；本块的子块成为上一块的子块。上一块是空块且不是父块时，改为删掉上一块。根列表的第一块：日记中不做任何事，文档里按普通段落处理。 |
| `Delete`（块尾） | 把可见顺序中的**下一块**合并进来（等同于在下一块块首按 Backspace）。 |
| `Tab` | 缩进：成为上一个同级块的**最后一个子块**；上一个同级块是折叠的就先展开。没有上一个同级块时不动。 |
| `Shift+Tab` | 反缩进：移到父块之后成为同级；原来排在它后面的同级块变成它的子块（Logseq 默认的“直接反缩进”）。根层级不动。 |
| `Mod+Shift+↑` / `Alt+Shift+↑` | 上移，**保持层级**：有上一个同级块就与它交换；是第一个子块时，移到父块的上一个同级块里（有子块就排在它的子块末尾，没有就成为它的第一个子块）；父块也没有上一个同级块时不动。 |
| `Mod+Shift+↓` / `Alt+Shift+↓` | 下移，与上移对称：有下一个同级块就排到它（连同子块）之后；是最后一个子块时，成为父块下一个同级块的第一个子块。 |
| `Mod+↑` / `Mod+↓` | 折叠 / 展开。 |
| `Mod+Enter` | 待办循环，见下文“任务”。 |
| `Mod+.` / `Mod+,` | 聚焦到当前块 / 退回上一层。 |
| `Esc` | 退出编辑，**选中当前块**（进入块选择）。退出聚焦用 `Mod+,` 或点路径里的“全部”。 |

| `Mod+;` | 展开 / 折叠当前块的子块（切换）。 |
| `Shift+↑` / `Shift+↓` | 块内扩展文字选区；已在块的首行 / 末行时改为**选中整块**（进入块选择并向上 / 下扩展）。 |
| `Mod+A` | 第一次选中块内全部文字；文字已全选时**选中整块**。 |
| `Ctrl+L`（Windows / Linux 为 `Alt+L`） | 清空当前块的文字。 |
| `Ctrl+U`（Windows / Linux 为 `Alt+U`） | 删除光标前的全部文字。 |
| 鼠标拖选、`Shift` 点击 | 选区跨过块的边界时，自动变成**块选择**（从起点块到终点块）。 |

### 自动配对

| 输入 | 结果 |
|---|---|
| `[` `{` `(` `` ` `` | 补上右半边，光标在中间；有选中文字时把它包起来。 |
| 右半边（`]` `}` `)` `` ` ``），而光标后正好是它 | 跳过，不重复输入。 |
| 在一对空括号中间按 `Backspace` | 两边一起删掉。 |
| `[[` | 打开卡片搜索（见下）。 |
| 全角 `【【`（中文输入法） | 换成 `[[]]` 并打开卡片搜索。 |
| 输入法正在组字时 | 都不处理。 |

Logseq 里 `* _ ~ ^ = / +` 在有选中文字时也会包起来，那是 Markdown 源码编辑的需要；Folio 是富文本编辑器，粗体、斜体等用 `Mod+B` / `Mod+I` 或输入 `**文字**` 自动转换，不做这项配对。

### `/` 命令（逐条对照 Logseq `src/main/frontend/commands.cljs` 的 `commands-map`）

输入 `/` 弹出菜单，按 Logseq 的分组列出；继续输入可过滤，`↑` `↓` 选择，`Enter` 执行，`Esc` 关闭。

| 分组 | Logseq 命令 | Folio |
|---|---|---|
| 基础 | 节点引用 `[[` | 卡片引用：打开卡片搜索 ✓ |
| | 节点嵌入 | 暂不做：随块引用一起做（M2） |
| 格式 | 链接 | 输入网址；有选中文字时把它变成链接 ✓ |
| | 图片链接 | 输入图片网址，插入图片 ✓ |
| | 下划线 | 开 / 关下划线 ✓ |
| | 代码块 | 当前块下插入代码块（列表外把当前段变成代码块）✓ |
| | 引用块 | 当前块显示为引用（Logseq 的 display-type quote；列表外为引用段落）✓ |
| | 数学块 | 插入 KaTeX 数学块 ✓ |
| 标题 | 正文、清除标题 | 当前行变回正文 ✓ |
| | 标题 1–6 | ✓ |
| 任务状态 | Backlog、Todo、Doing、In Review、Done、Canceled | 设为对应状态 ✓（见下文“任务”） |
| 任务日期 | 截止日期、计划日期 | 选日期，显示在块末尾 ✓ |
| 优先级 | 无、低、中、高、紧急 | ✓，显示在状态图标后 |
| 时间与日期 | 明天、昨天、今天 | 插入指向那天日记的链接 ✓ |
| | 当前时间 | 插入 `HH:mm` ✓ |
| | 日期选择器 | 选日期，插入那天日记的链接 ✓ |
| 列表类型 | 编号列表、子项编号 | 当前块所在列表 / 当前块的子项改为编号列表（再执行一次改回）✓ |
| 高级 | 上传文件 | 暂不做：附件存储（§4.6）在 M2 |
| | 评论、查询、高级查询、查询函数、计算器、模板、嵌入 HTML / 视频 / 推文、添加属性 | 暂不做：依赖属性、查询、模板等尚未建立的功能（M2–M6） |

`[[` 卡片搜索：按标题过滤卡片库；`Enter` 插入卡片链接；没有同名卡片时第一项是“新建卡片「…」”。

### 任务（对照 Logseq 内置属性 `logseq.property/status`）

| 状态 | Logseq 图标 | Folio 图标与颜色 |
|---|---|---|
| Backlog 待规划 | 虚线圆 | 虚线圆环，浅灰 |
| Todo 待办 | 空心圆 | 圆环，深灰 |
| Doing 进行中 | 右半填充的圆 | 圆环 + 右半填充，黄 |
| In Review 审核中 | 实心圆 + 对话气泡 | 实心圆 + 气泡，蓝 |
| Done 已完成 | 实心圆 + 勾 | 实心圆 + 勾，绿；文字变灰并划线 |
| Canceled 已取消 | 实心圆 + 叉 | 实心圆 + 叉，红；文字变灰并划线 |

- 状态图标是圆形，约 18 px，占圆点的位置（与 Logseq 一样在块的最左侧；Folio 不再同时显示圆点）。
- **点状态图标**弹出状态菜单（6 种状态 + “取消任务”），与 Logseq 点状态值打开选择器相同。拖动图标移动块。
- `Mod+Enter`：普通 → Todo → Doing → Done → 普通；Backlog / In Review / Canceled 按一次回到 Todo（与 Logseq `cycle-todo` 相同）。
- `Enter` 新建的块**不继承状态**（Logseq 新块只继承父块与页面）。
- 任务块行首按 `Backspace`，或在空的任务块按 `Enter`：**去掉任务状态，变回普通块**，内容和位置不变；再按 `Backspace` 才与上一块合并（Notion 的做法；Logseq 会直接合并，那样会连同状态把整行删掉）。
- **卡片默认是正文**（文档模式）：日记是大纲，卡片是文档。卡片里只有自己输入 `- ` / `1. ` 才出现列表，其余都是普通段落：
  - `[ ] `、`/待办` 或 `Mod+Enter` 把当前段落变成任务行；
  - 任务行后按 `Enter`，下一行是**普通段落**；空的任务行按 `Enter`、任务行行首按 `Backspace`，都变回**普通段落**（不是带圆点的列表项）；
  - 在普通段落上设置优先级或日期，会先把它变成任务（这两项在 Logseq 里也属于任务）；
  - 提炼成卡片时，被提炼块的子块变成卡片里的普通段落（块 id 不变），更深的层级保留为列表。
- 日记（大纲模式）里，去掉状态的任务行变回普通的大纲条目。

### 复制、剪切、粘贴

| 操作 | 规则 |
|---|---|
| 块选择中 `Mod+C` / `Mod+X` | 复制 / 剪切选中的块（连同子块）：纯文本是带缩进的 Markdown 大纲（`- `），富文本保留结构。剪切后粘贴视为移动，块 id 不变；复制后粘贴是新块。 |
| 粘贴多段内容到块里 | 粘贴的内容含列表、标题或多个段落时，拆成多个块插在当前块之后（当前块为空时替换它），列表的层级保留；纯文本按 Markdown 解析（`- `、`* `、`1. `、`[ ] `、`# ` 和缩进），用空行分隔的段落各成一块。 |
| 粘贴单行内容 | 插入当前块。 |
| 选中文字后粘贴网址 | 把选中文字变成链接。 |
| `Mod+Shift+V` | 作为纯文本粘贴进当前块，不拆块。 |

## 块选择（`Esc` 之后）

| 操作 | 规则 |
|---|---|
| `↑` / `↓` | 选中可见顺序中的上一块 / 下一块。 |
| `Shift+↑` / `Shift+↓` | 扩展选择。 |
| `Enter` | 编辑选中的块（光标在末尾）。 |
| `Esc` | 取消选择。 |
| `Backspace` / `Delete` | 删除选中的块（连同子块）。 |
| `Tab` / `Shift+Tab`、`Mod+Shift+↑/↓`、`Mod+Enter` | 作用于所有选中的块。 |
| `Mod+A` | 选中父块；已在顶层时选中全部块。 |
| `Mod+C` / `Mod+X` | 复制 / 剪切选中的块（见上）。 |
| `Shift` 点击另一块 | 扩展到那一块。 |

选中多个块时，只对“顶层”选中块操作（子块随父块移动）。

## 拖放

- **拖圆点**移动块（连同子块）；点圆点聚焦。
- 拖到某块上方时：指针距该块文字左缘超过 **50 px** → 放成它的**第一个子块**；在根列表第一块的上边缘 **16 px** 内 → 放到它**前面**；其余 → 放到它（连同子块）**后面**，同级。
- 拖动时显示一条放置线，放成子块时线向右缩进。不能放进自己的子树。
- 列表外的块（段落、标题、引用、代码块）拖左侧的六点把手；也可以放到列表外的块之间：按指针在该块的上半还是下半，放到它前面或后面。列表项放到列表外时自成一个列表；段落放进大纲时成为一个块。
- **跨窗格（分屏）**：拖到另一侧窗格默认**复制**，复制出的块换新 id（块引用不会指向两处）；同一窗格内（如日记的不同日子之间）默认**移动**，保留 id。按住 ⌥ 强制复制、⌘ 强制移动（同 Finder）。跨文档移动先插入目标再删除源，中途失败只会多一份，不会丢。

## 输入手感（参考 Notion、Heptabase、Bear、Craft）

Logseq 的规则管“结构”，下面这些管“手感”，来自对这几个编辑器的对照和在 Folio 里实际输入时发现的别扭之处：

| 情况 | 规则 | 参考 |
|---|---|---|
| 刚用 `- ` `# ` `> ` `1. ` 等 Markdown 快捷方式转换完，按 `Backspace` | 撤回转换，恢复成刚输入的字符 | Notion、Bear |
| 标题行行首按 `Backspace` | 先变回普通段落，再按一次才与上一块合并 | Notion |
| 卡片正文第一行按 `↑`，或在正文开头按 `Backspace` | 光标回到卡片标题末尾 | Notion、Heptabase、Craft |
| 卡片标题里按 `↓`，或在末尾按 `→` | 光标进入正文开头 | 同上 |
| 卡片标题中间按 `Enter` | 光标后的文字移到正文第一行 | Notion |
| 点击正文最后一行下方的空白 | 在末尾继续写；最后一块不是空行时先补一个空行 | Notion |
| 不在列表里按 `Tab` / `Shift+Tab` | 不做任何事，但光标留在编辑器里（不能让焦点跳出编辑区）；代码块里 `Tab` 插入两个空格 | 所有编辑器 |
| 输入时光标接近窗口上下边缘 | 提前滚动，光标与边缘保持约 100 px | Bear、iA Writer、Notion |
| 空行的提示文字 | “输入文字，或按 / 插入” | Notion |
| 鼠标拖选跨过多行 | 日记（大纲）里变成块选择（Logseq）；卡片（文档）里保持文字选区（Notion） | — |

## 暂不做

多光标；块引用 `((` 与嵌入（M2，随块引用一起做）；在编辑中、未选中文字时 `Mod+C` 复制块引用（同上）；`Mod+Shift+M` 移动到其他页面；`t o` 一类按键序列。
