# 打卡（习惯）

> 2026-11-02 起。代码：`web/src/docs/habits.ts`（存储与统计），`web/src/habits/`（界面）。

## 目标

在任务页加一个“打卡”视图，用来坚持每天或每周的习惯。用户可以选择在每天的日记里也显示当天要打的卡，并直接在日记里打勾。

## 参考了谁

| 产品 | 借鉴的做法 |
|---|---|
| Loop Habit Tracker | 主列表每行显示最近几天，点一下就打卡；“习惯强度”用指数移动平均，几天没做不会清零；支持每周几次、数量型（至少 / 至多）、跳过 |
| Streaks | 每周 N 次的目标；跳过某天不打断连续 |
| TickTick | 打卡时可以写备注；连续天数按自己定的频率算，而不是每天 |
| 习惯类应用的共同经验 | 漏了一天不惩罚（不弹窗、不清零强度）；按周目标比固定日子更宽容 |

## 模型

一个习惯有：

- 名称、图标（emoji，可空）、颜色（8 种之一）
- **怎样算完成**：打勾；或记数量，带目标、单位和方向（至少 8 杯水 / 至多 2 杯咖啡）
- **什么时候**：每天；每周几（周一到周日任选）；每周 N 次（1–6，哪天做都行）
- 每天的记录：数量（打勾记为 1）或“跳过”；每天可以有一条备注
- 归档（不再显示在日记和主列表，数据保留）、删除

### 统计

- **当前连续 / 最长连续**：按“该做的日子”数；每周 N 次的习惯按周数。跳过的日子不算也不打断。今天还没做不打断。
- **习惯强度**（0–100%）：每个该做的日子（或每周）做一次指数移动平均，越近权重越大。半衰期 13 次（每周型 4 周）：每天坚持一个月后断两周，强度大约减半。这是自己写的，没有用 Loop 的代码（GPL）。
- **本周**：完成数 / 本周要求的次数。
- **累计完成**。
- 开始日期是创建那天；在日历上补打更早的日子时，从最早那天算起。

## 存储

在工作区文档（`ws`）里，旧版本不认识这些 map，会原样保留：

- `habits`：习惯 id → map，字段 `name`、`icon`、`color`、`schedule`（`daily`、`days:1,3,5`、`weekly:3`）、`target`/`unit`/`limit`（数量型才有）、`created_at`、`order`、`archived_at`、`deleted_at`；子 map `log`（日期 → 数量或 `"skip"`）、`notes`（日期 → 文字）
- `prefs.journal_habits`：日记里是否显示打卡，默认显示，各设备同步

每个习惯只由一台设备创建，所以字段按字段合并；两台设备打不同的日子都保留，同一天以后写的为准。读的时候对未知或损坏的值取默认值。

## 界面

- 任务页的第四个视图“打卡”；任务页记住每台设备上次看的视图。
- 每行：图标、名称、频率和连续天数，右边最近 7 天（手机上 5 天）。点一下打勾或取消；数量型弹出输入框（可以 +/−，或一键达成目标）。右键或长按：跳过、备注、清除。
- 点名称展开：统计、最近 18 周的日历（每格都能点，用来补打）、最近的备注、编辑 / 排序 / 归档 / 删除。
- 日记：每天日期下面一排小标签，只列当天该做、已经创建、没有归档的习惯；未来的日子不显示。
