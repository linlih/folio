# 目录（长卡片按标题跳转）

状态：已实现（2026-11-23，v0.1.41）。草图：`design/mockups/toc.html`（电脑 + 手机）。

## 1. 现在有什么

- **电脑**：详情面板（`web/src/shell/DetailsPanel.tsx`，默认收起，Ctrl+⌘+I 或标签栏右侧按钮打开，记住开关状态）第一节就是“目录”。数据来自 `bodyFacts`（`web/src/docs/card.ts`）：所有非空标题的 bid / 级别 / 文字，按最高一级缩进；编辑停 300 ms 后刷新。点一项走 `openAt` → `flashBlock`（`web/src/editor/reveal.ts`）：标题平滑滚到**正中**并闪 1.6 秒。分屏时面板跟随聚焦的一栏。
- **手机**：没有详情面板，也没有其他入口——**手机上不能按标题跳转**。
- **缺的**：
  1. 没有“当前在哪一节”的高亮，滚动时目录不动。
  2. 标题在**折叠的列表项**里（大纲卡片常见）时点了没反应：节点在 `display:none` 里，`scrollIntoView` 不动（WebKit 实测）。
  3. 大纲卡片**聚焦（zoom）**在某一项时，范围外的标题同样跳不过去（聚焦是视图状态，`editor/outliner/focus.ts`）。
  4. 滚到正中适合反链（要看上下文），目录习惯是滚到顶部。
  5. 日记标签页面板显示“打开一张卡片…”，日记不在本次范围。

## 2. 别的应用怎么做

| 应用 | 位置 | 何时出现 | 当前位置高亮 | 折叠 | 手机 |
|---|---|---|---|---|---|
| Notion | 正文右缘一列短横线，悬停展开成列表；另有“目录”块 | 默认开，≥2 个标题；页面菜单可关 | 有 | 无 | 无浮动目录，只有目录块 |
| Obsidian | 右侧栏“大纲”面板 | 面板开着就在 | 有 | 有（按级折叠） | 侧栏抽屉里 |
| Typora / 思源 | 侧栏“大纲” | 手动开 | 有 | 有 | —— |
| Google Docs | 左侧“文档大纲”面板 | 手动开 / 有标题时可开 | 有 | 有 | 菜单里打开 |
| 飞书 / 语雀 | 飞书左侧目录、语雀右侧大纲，宽屏常驻 | 有标题即显示 | 有 | 有 | 底部/顶部“目录”按钮 → 弹出列表 |
| Bear | 侧边信息栏里的目录 | 手动开 | —— | —— | 菜单里 |
| Apple Notes | 无目录，标题可折叠 | —— | —— | 标题折叠 | —— |
| Logseq | 无内置目录（插件） | —— | —— | 块本身可折叠 | —— |

共同点：**一个固定的侧边位置**（面板/侧栏）是主流；都高亮当前一节；点一项把标题滚到顶部；手机上一律“菜单/按钮 → 弹出列表，点了就关”。Notion 的右缘浮动条是少数派，需要正文右侧留白，且与面板重复。

## 3. 建议（一个方案）

**电脑：继续用详情面板里已有的“目录”，把它做好；手机：卡片 ⋯ 菜单加“目录”，底部弹出同一份列表。** 不新增浮动条，不改存储格式。

### 3.1 电脑（详情面板）
1. **当前一节高亮**：加粗 + 左侧 2px 强调色细线。计算：卡片所在 `.view` 滚动时（rAF 节流），取“顶部在视口上方 1/4 以内的最后一个**可见**标题”；跳过高度为 0 的（折叠里的）标题——WebKit 实测不跳过会误判成折叠里的那个；滚到底时取最后一个可见标题。
2. **跳转**：标题滚到正文**顶部**（`block: "start"` + `scroll-margin-top` 约 16px，WebKit 支持），保留闪一下。点击后立即高亮点的那一项，等 `scrollend`（WebKit 支持，另加超时兜底）再恢复跟随滚动，避免途经的各节闪过。
3. **折叠里的标题**：先展开它的祖先项再跳（和点折叠箭头一样，写的是已有的 `collapsed` 属性，会同步到其他设备——与 Workflowy/Logseq 跳转时展开一致）。
4. **聚焦范围外的标题**：先退出聚焦再跳。
5. 面板目录较长时，当前项保持在面板可见范围内（只滚面板自己）。
6. 分屏：跟随聚焦的那一栏（现状）；同一卡片开在两栏时，以聚焦栏的滚动为准。

### 3.2 手机
- 两个入口，**卡片有 ≥2 个标题才出现**（同 Notion 门槛；只有 1 个没必要）：顶栏右侧的目录按钮（读到一半也够得着——卡片的 ⋯ 在标题行里，会随标题滚走），和卡片 ⋯ 菜单第一项“目录”。
- 底部弹出的 sheet：拖动条、标题“目录”、底部安全区；当前一节同样是强调色细线；点一项关闭并跳转；点空白处、下拉拖动条、Esc / 安卓返回关闭。
- 跳转规则同电脑（顶部、展开折叠、退出聚焦）。

### 3.3 不做
- Notion 式右缘浮动条：与面板重复，680px 正文在 1100 宽 + 侧栏下右侧留白不够。
- 目录块（插入到正文的目录）：要改文档内容，暂不需要。
- 目录内折叠、搜索框、快捷键：先不加，需要再说。
- 日记的目录。

## 4. 兼容
不改存储的文档、不加新字段。唯一的写入是跳到折叠项里时展开祖先，用的是已有 `collapsed` 属性，等同用户手动展开。

### 3.4 样式
层级靠缩进 + 字号 + 颜色（一级深色 500 字重，二级灰 12.5px，三级更浅），不用圆点。左侧 1px 细线，当前一节是线上 2px 强调色的一段，`transform` 平滑滑到该行，文字变强调色。行高 28px，悬停浅底，长标题省略号 + 悬停全文。无渐变、无重阴影；`prefers-reduced-motion` 时不动画。

## 5. 实现（2026-11-23）
- `web/src/card/tocState.ts`：`currentHeading`（跳过高度为 0 的隐藏标题；滚到底取最后一个）、按 pane+卡片存当前标题、点选后保持到 `scrollend`（兜底 1.5 秒）、手机 sheet 开关与是否提供。
- `web/src/card/Toc.tsx` + `toc.css`：`TocList`（面板与 sheet 共用）、`TocSheet`。
- `web/src/editor/reveal.ts`：`flashBlock(view, bid, align)`，先展开折叠的祖先项、必要时退出聚焦；反链跳转也受益。
- `web/src/card/reveal.ts`：`openAt(..., align)`。
- `CardView.tsx`：跟踪当前标题；手机上 ⋯ 菜单项与 sheet。`PhoneBars.tsx`：顶栏目录按钮。`DetailsPanel.tsx`：用 `TocList`。
- 测试：`web/test/toc.test.ts`；WebKit 端到端（1100 电脑面板、390 手机）。

## 5a. 原实现要点
- `web/src/card/` 加一个小 hook：给定 pane + editor，算当前标题 bid，存到 shell 状态（按 pane），面板和手机 sheet 都读它。
- `editor/reveal.ts`：`flashBlock` 加 `align: "start" | "center"`；找到节点后先展开折叠祖先 / 退出聚焦。
- `DetailsPanel.tsx`：高亮 + 面板内保持可见。
- `CardView.tsx` CardMenu：手机加“目录”项 + sheet。
- i18n：复用 `panel.outline`（目录 / Outline）。
- 测试：vitest（当前标题计算跳过隐藏标题、展开祖先）；WebKit 端到端（电脑面板跟随滚动、点跳到顶部、折叠里的标题；手机 sheet）。
